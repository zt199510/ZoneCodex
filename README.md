# ZoneCodex

第一版基础代码：使用 Electron、React 和 TypeScript 构建的个人 AI 桌面工作空间。

## 当前功能

- 多会话聊天、Markdown 展示、停止生成、本地自动保存和关闭保存保护。
- 会话首次发送自动标题、重命名、标题/消息搜索、置顶、归档和恢复；归档保留完整记录，不提供永久删除。
- 统一输入框与「＋」附件浮层，支持多选文本/代码文件、移除附件；添加附件即允许在当前会话中使用其内容。
- 模型工具循环，支持时间查询、已授权附件快照的读取、搜索和受控提案；正式聊天和工具调用统一使用真实模型流式响应。
- 工作区可选，每个无项目会话有稳定的默认目录；同一套本地工具处理相对和绝对路径，支持受限文本的列出、搜索、读取、新建和基于完整读取的编辑。
- 输入框权限菜单按截图显示“请求批准”（`default`）、“帮我批准”（`auto-approve`）和“完全访问权限”（`full-access`）。请求批准沿用默认目录内直接写入、目录外按需批准及非沙箱命令批准；完全访问权限由用户选择。“帮我批准”的风险审批模块已通过离线检查，但模型接线等待明确授权，当前选择时提示尚未启用并保留原实际模式；`AGENTS.md` 不扩大权限。
- 文件与命令的批准请求在输入框上方显示同宽悬浮弹窗；创建、编辑文件显示审批原因、操作与完整目标路径，命令显示审批原因、工作目录及可读命令，取消和确认按钮位于右下角。
- 输入框附件与权限按钮、工作区状态与右侧按钮均统一对齐；对话侧栏滚动条贴右边缘，列表内容保留留白。
- 基于 xterm 和 node-pty 的 PowerShell 终端，以及可调整的工作台布局。

当前附件上限为 8 个文件、单文件 32 KiB、合计 128 KiB。文件新建/编辑仍限小型文本。Windows 命令 OS 沙箱及自动审批器尚未接入，获批程序可能访问其他文件、网络或启动子进程。图片输入、目标/计划/绘图模式、SSH 和 MCP 留待后续实现。

当前学习安排为[第四十四课：自动审批接入与三种授权模式闭环](ZoneCodex学习计划/55-第四十四课-自动审批接入与三种授权模式闭环.md)：接通既有风险审批模块，风险、异常和超时复用人工批准，补齐取消、迟到结果与执行前二次校验；真实模型文件闭环安排在实施后验收。本轮仅编写课程，当前“帮我批准”仍未启用，未授权模型外发。Windows 命令沙箱下一课研究，第45课尚未创建。

## 开发

安装 Node.js 与 npm，在项目根目录运行：

```sh
npm install
npm run dev
```

真实模型调用需要本地配置 `MODEL_ENDPOINT`、`MODEL_NAME` 和 `MODEL_API_KEY`。密钥仅用于主进程，不应写入源码或学习文档；`.env.local` 不纳入 Git。终端功能当前以 Windows PowerShell 为基础。

## 本地验证

```sh
npm run typecheck
npm run lint
npm run build
```

应用运行时只使用真实模型的 Responses SSE 流，不提供模拟聊天入口。会话存储为版本6，迁移版本1–5前备份原文件，保存的历史不恢复运行授权。真实模型调用需要配置 `MODEL_ENDPOINT`、`MODEL_NAME` 和 `MODEL_API_KEY`，端到端结果需实际验收。

## 项目与课程

`src/main` 负责系统、模型、工具与存储；`src/preload` 暴露业务接口；`src/shared` 定义共享协议；`src/renderer` 负责工作台界面。`build/` 中的图标与打包资源属于源码，`out/`、`dist/`、本地备份及测试截图不纳入 Git。

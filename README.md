# ZoneCodex

第一版基础代码：使用 Electron、React 和 TypeScript 构建的个人 AI 桌面工作空间。

## 当前功能

- 多会话聊天、Markdown 展示、停止生成、本地自动保存和关闭保存保护。
- 回复区按 Codex App 截图调整字体、段落、列表、代码与表格；过程文字与真实工具条目按顺序连续显示，工具详情采用树状缩进，最终回答在过程区外显示。进入最终回答时过程区仅自动收起一次，保留后续手动开合；失败或取消的已有调用记录也会保存。
- 会话首次发送自动标题、重命名、标题/消息搜索、置顶、归档和恢复；归档保留完整记录，不提供永久删除。
- 统一输入框与「＋」附件浮层，支持多选文本/代码文件、移除附件；添加附件即允许在当前会话中使用其内容。
- 模型工具循环，支持时间查询、已授权附件快照的读取、搜索和受控提案；正式聊天和工具调用统一使用真实模型流式响应。
- 工作区可选，每个无项目会话有稳定的默认目录；同一套本地工具处理相对和绝对路径，支持受限文本的列出、搜索、读取、新建和基于完整读取的编辑。
- 输入框提供“请求批准”（`default`）、“帮我批准”（`auto-approve`）和“完全访问权限”（`full-access`）三种实际模式。有效范围内文件写入直接执行，默认与帮我批准的范围内命令走官方沙箱；需要批准时，请求批准显示人工弹窗，帮我批准先独立评估具体操作，仅严格的 `safe` 结果自动批准，风险、异常或超时复用人工弹窗；完全访问权限由用户选择。旧 npm 的非沙箱执行缺少可信用户任务时仍转人工批准；`AGENTS.md` 不扩大权限。
- 文件与命令的批准请求在输入框上方显示同宽悬浮弹窗；创建、编辑文件显示审批原因、操作与完整目标路径，命令显示审批原因、工作目录及可读命令，取消和确认按钮位于右下角。
- 输入框附件与权限按钮、工作区状态与右侧按钮均统一对齐；对话侧栏滚动条贴右边缘，列表内容保留留白。
- 可调整的工作台布局；工程保留基于 xterm 和 node-pty 的 PowerShell 终端能力，当前主工作台未挂载终端面板。

当前附件上限为 8 个文件、单文件 32 KiB、合计 128 KiB。文件新建/编辑仍限小型文本。Windows 默认命令使用固定官方 Codex CLI 0.160.1 的 elevated 沙箱路径，主进程核验单次执行计划，原生 Job 监督器负责进程树生命周期。系统初始化和访问限制交由官方后端处理；初始化、启动或命令失败如实返回，不自动改用普通权限重跑。用户批准的非沙箱命令具有本机当前用户的文件和网络访问权限。图片输入、目标/计划/绘图模式、SSH 和 MCP 留待后续实现。

## 开发

安装 Node.js 与 npm，在项目根目录运行：

```sh
npm install
npm run dev
```

真实模型调用需要本地配置 `MODEL_ENDPOINT`、`MODEL_NAME` 和 `MODEL_API_KEY`。密钥仅用于主进程，不应写入源码或学习文档；`.env.local` 不纳入 Git。终端功能当前以 Windows PowerShell 为基础。

## 本地验证

```sh
npm run typecheck
npm run lint
npm run build
```

应用运行时只使用真实模型的 Responses SSE 流，不提供模拟聊天入口。会话存储为版本6，迁移版本1–5前备份原文件，保存的历史不恢复运行授权。真实模型调用需要配置 `MODEL_ENDPOINT`、`MODEL_NAME` 和 `MODEL_API_KEY`，端到端结果需实际验收。

# 第一课：读通两个入口和一次 IPC

## 本课目标

理解自己的桌面窗口如何出现、React 如何进入窗口，以及点击按钮后消息如何到达主进程。本课不增加依赖，不接入模型。

## 1. 确认项目位置与运行状态

在 VS Code 打开 `D:\AiTools\ZoneCodex\ZoneCodex`。

如果尚未运行，在终端执行：

```powershell
npm run dev
```

如果安装依赖尚未成功，先处理安装错误。如果窗口已经在运行，不要重复启动。预期看到模板首页和 Send IPC 按钮。

记录：窗口是否打开？终端是否有报错？未成功时先定位问题，不把此步骤标记为完成。

## 2. 从 React 入口开始读

打开 `src/renderer/src/main.tsx`，找到：

```tsx
createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <App />
  </StrictMode>
)
```

理解：

- createRoot 创建 React 根节点，把组件挂载到 HTML 的 root 元素。
- App 是根组件，对应熟悉的 App.vue。
- TSX 允许在 TypeScript 中写 JSX。
- `!` 是非空断言，仅影响类型检查，不会在运行时创建缺失的 DOM 元素。
- StrictMode 提供开发检查，部分渲染和 Effect 行为在开发时可能额外执行，用于发现问题，不等于正式版本重复执行所有操作。

练习：在 `src/renderer/index.html` 找到 root 容器，确认两端名称一致。

## 3. 做一个最小界面修改

打开 `src/renderer/src/App.tsx`，将页面中的 `Powered by electron-vite` 改为 `ZoneCodex · 学习版`，保存并观察窗口。

这一步由学习者亲手完成。注意 React 的 className、事件 onClick、组件函数和 return 的写法。

验收：修改确实显示；能解释自己改的是 React 源码而非 out 中的编译文件。

## 4. 追踪 Send IPC

在 App.tsx 找到：

```tsx
const ipcHandle = (): void => window.electron.ipcRenderer.send('ping')
```

然后找到按钮的 `onClick={ipcHandle}`。这里传递的是函数，点击时才调用；与在 JSX 中直接调用函数不同。

打开 `src/preload/index.ts`，找到：

```ts
contextBridge.exposeInMainWorld('electron', electronAPI)
```

这说明页面使用的 window.electron 是通过 preload 暴露的接口。它不是 React 内置变量。

打开 `src/main/index.ts`，找到：

```ts
ipcMain.on('ping', () => console.log('pong'))
```

点击 Send IPC，观察启动应用的终端中的主进程日志。预期看到 pong，页面上不会自动出现这段文字。

调用路径：用户点击 → React 事件函数 → preload 暴露的发送接口 → 主进程 ping 监听器 → 主进程日志。

当前使用 send/on，只发送事件，没有实现请求结果返回。之后的选择文件夹练习再学习 invoke/handle。

## 5. 读取桌面入口

在 main/index.ts 依次定位：

1. app.whenReady()：等待 Electron 初始化。
2. new BrowserWindow(...)：创建窗口。
3. webPreferences.preload：指定编译后的预加载脚本。
4. loadURL / loadFile：开发时加载开发服务器，生产时加载编译后的本地页面。
5. window-all-closed：处理所有窗口关闭后的行为。

理解：`src/main/index.ts` 是桌面主进程入口；`src/renderer/src/main.tsx` 是 React 界面入口。名字相似，但职责不同。

## 6. 自测题

先自行回答，再结合源码检查：

1. 修改按钮文字应该去哪一层？改变窗口初始尺寸呢？
2. window.electron 是谁提供的？index.d.ts 是否真正创建了它？
3. 为什么 ping 的日志出现在终端，而不是消息列表？
4. preload 是否是独立的第三个进程？
5. 为什么不直接修改 out/main/index.js？
6. 当前自动更新是否已经可用？你根据什么判断？

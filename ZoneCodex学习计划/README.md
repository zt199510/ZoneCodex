# ZoneCodex 学习计划

这套文档面向有 Vue 开发经验、希望亲手复刻 AI 桌面助手的学习者。通过自己的 ZoneCodex 项目学习 React、TypeScript、Electron，再逐步实现聊天、终端、SSH、MCP 和自动更新。

## 项目与使用方式

- 实践项目：`D:\AiTools\ZoneCodex\ZoneCodex`。
- 参考项目：https://github.com/239573049/NextCoWork
- 学习方法：阅读少量相关源码 → 自己实现一个小功能 → 验证效果 → 解释原理 → 记录问题。
- 原项目用于对照设计，不要求先运行，也不按目录从头到尾照抄。
- 不按固定天数赶进度，每一阶段以验收结果为准。

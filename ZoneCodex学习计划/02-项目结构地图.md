## 运行边界

main 负责系统与网络，renderer 负责页面。preload 是窗口关联的桥接脚本，不是独立的第三个进程；页面通过 window.api 使用明确业务接口，不直接读取文件或启动系统进程。shared 放跨边界使用的类型与纯校验，不导入 UI 或 Electron 运行时。

独立风险审批只接收已验证的本轮用户任务与固定操作载荷，不使用聊天历史或副作用工具；仅严格的 `safe` 批准，其他结果或异常转人工批准。执行前继续复核取消、权限版本、路径与配置。本课限定的真实文件闭环及命令人工回退已验收，取消、异常和超时仍仅离线验证。Windows 命令沙箱未实现，风险判断不提供进程或网络隔离，课程自测状态未提前标记。

`index.ts` 只保留启动和窗口创建；`app-runtime.ts` 具名接入模块注册、业务互斥和清理顺序。业务 IPC 注册归各功能模块，授权 Map、运行句柄和计时器仍由原领域拥有者管理。模型传输与文件底层使用 `errors.ts`，不再反向依赖 Agent 循环实现。

## Vue 对照

| Vue | 当前 React 实现 |
|---|---|
| createApp / App.vue | createRoot / App.tsx |
| props / emits | Props / 回调函数 |
| v-model | value / onChange |
| ref/reactive | useState；更新后在下一次渲染拿到新值 |
| composables | 自定义 Hooks |
| 挂载第三方组件、卸载清理 | DOM ref + Effect setup/cleanup |

Effect 用于外部订阅与资源同步；派生值通常直接计算，不把所有 watch 机械翻译成 Effect。

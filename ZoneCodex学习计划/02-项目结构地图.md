## 运行边界

main 负责系统与网络，renderer 负责页面。preload 是窗口关联的桥接脚本，不是独立的第三个进程；页面通过 window.api 使用明确业务接口，不直接读取文件或启动系统进程。shared 放跨边界使用的类型与纯校验，不导入 UI 或 Electron 运行时。

当前 index.ts 仍保留窗口创建和部分 IPC 注册；模型流、窗口操作和关闭保护各自注册自己的通道。这是当前课程规模下的安排，并不代表已经有完整 Agent 后台。

## 页面与状态职责

| 文件（相对 renderer/src） | 当前职责 |
|---|---|
| App.tsx | 组装标题栏、侧栏和 ChatWorkspace |
| features/conversation/useConversation.ts | 版本 4 会话库唯一状态源、新建/切换/清空，协调请求、项目选择和保存 |
| features/conversation/useOperation.ts | loading/idle/generating/saving/selecting 同步互斥 |
| features/conversation/useConversationStorage.ts | 启动加载、整库保存、防抖、失败暂停和重试 |
| features/conversation/useCloseGuard.ts、CloseGuard.tsx | 页面关闭请求处理、三种选择和保存后关闭 |
| features/chat/useChatRequest.ts | 请求 ID 与会话归属、增量和终态更新、停止 |
| features/chat/context.ts | 构造成功问答的文本上下文，隔离最近项目轮次之前的历史 |
| features/chat/chat-mode.ts | 根据真实/模拟/流式调试来源和附件状态推导内部请求模式 |
| features/project/useProjectSelection.ts | 直接多选、追加、移除和撤销；添加即授权 |
| features/project/ComposerAttachments.tsx、AttachmentCards.tsx | “＋”同宽浮层、输入框内附件卡片与调试设置 |
| features/conversation/capacity.ts | 发送前容量检查的纯函数 |
| features/chat/ChatWorkspace.tsx | 草稿、消息区、确认框及滚动；保留滚动 useLayoutEffect |
| features/chat/ChatInput.tsx | 受控输入、输入法、发送和停止按钮 |
| features/chat/MessageList.tsx | 按角色展示正文及消息状态 |
| features/chat/MarkdownContent.tsx | 助手 Markdown 派生展示，HTML/URL/图片限制 |
| components/layout/useWindowControls.ts | 窗口状态订阅和按钮操作 |
| assets/base.css | 颜色、字体、标题栏变量和基础样式 |
| assets/main.css | 样式导入入口；具体规则按工作台、聊天、项目、Markdown、弹窗、终端和响应式拆分 |

会话存储与模型上下文仍保存原始文字，Markdown 是展示结果。终端输出使用独立显示组件，不写入聊天消息来冒充助手回复。

## Vue 对照

| Vue | 当前 React 实现 |
|---|---|
| createApp / App.vue | createRoot / App.tsx |
| props / emits | Props / 回调函数 |
| v-model | value / onChange |
| ref/reactive | useState；更新后在下一次渲染拿到新值 |
| composables | 自定义 Hooks |
| 挂载第三方组件、卸载清理 | DOM ref + Effect setup/cleanup |

Effect 用于外部订阅与资源同步；派生值通常直接计算，不把所有 watch 机械翻译成 Effect。

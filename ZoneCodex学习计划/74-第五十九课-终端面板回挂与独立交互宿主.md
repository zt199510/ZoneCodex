## 1. 本课目标与前置条件

创建时核对：主进程已 `registerLocalTerminal()`，preload 已暴露 `startTerminal` / `writeTerminal` / `resizeTerminal` / `closeTerminal` / `onTerminalEvent`，`TerminalPanel` 与 `terminal.css` 已存在，但 `App.tsx` **未挂载**面板（孤儿 UI）。本课目标是把该栈接回工作台布局，使学习者能在桌面**亲手**打开本地 shell（PowerShell/cmd 设置已有解析），并证明它与聊天 Agent 宿主隔离。

本课要让学习者能回答：

1. 为什么「集成终端」是交互宿主，而不是又一个 Agent 工具？  
2. 回挂时布局/焦点/关闭/窗口销毁应如何与会话切换、设置页共存？  
3. 如何用自动或手工证据证明：开终端零模型请求、PTY 输出未进入 Agent 上下文？  
4. 本课明确不做什么（MCP、把终端输出喂模型、SSH 远程壳）？

### 1.1 一句话目标

将已有终端栈回挂到桌面壳，成为与聊天并列的独立交互宿主：不进 tool-loop、不调 Agent、不授予 Agent 凭据。

### 1.2 前置能力清单

| 课 | 必须带走 | 本课用法 |
| -- | -------- | -------- |
| 早期终端/PTY 基线 | `local-terminal`、shared 合同、xterm 面板 | 复用，不重写协议；本课主攻 UI 回挂与隔离验收 |
| 第54/58课 | 桌面薄宿主 vs 核心；IPC 合同 | 终端走自己的 IPC，不塞进 `desktop-agent-host` 编排 |
| 第55课 | 帮助/导入零启动精神 | 开终端 ≠ 启动 Agent；无任务时仍可开终端 |
| 第57/58课 | 被动重开零请求；显式继续才跑 Agent | 终端显隐不得破坏该精神 |

### 1.3 明确不做

- **MCP、Skills、插件、SSH、远程 shell、Computer Use、内置浏览器产品化**
- 把终端输出/选中文本自动注入模型、tool 结果、instructions 或 checkpoint  
- 新增「Agent 控制终端」类工具或让模型 `writeTerminal`  
- 放宽第56容量；复活批准/读取凭据/命令票据  
- 借机重做整套布局系统、多标签 IDE、或 CLI REPL 持久会话  
- 把第56/57/58 open 项改写成已通过；不宣称「框架已适合接 MCP」仅因终端可见

## 2. 用 Vue 经验理解本课

| Vue 中的经验 | 本课对应 | 要理解的区别 |
| ------------ | -------- | ------------ |
| 页面里嵌一个独立 `<iframe>` 或外部编辑器 | 工作台嵌 xterm 面板 | iframe 不共享 Vuex；终端不共享 Agent 上下文 |
| `v-if` 挂载重型组件，卸载时 `onBeforeUnmount` 清理 | 打开/关闭面板时 start/close PTY | 必须在窗口关闭与面板关闭两条路径都停进程 |
| 路由切换不卸载全局 music player | 切会话时可选择保持或关闭终端——**实施时冻结一种**并测 | 默认建议：切会话不自动把输出送给 Agent；是否杀 PTY 写清 |
| 设置页与主页面互斥 | 设置打开时终端可隐藏或禁用焦点 | 审批/关闭保护对话框仍以聊天面为准（沿用现逻辑） |
| 组件库「只展示、不发 API」 | 终端面板只调 `window.api.*Terminal*` | 禁止 `import` agent 请求 hook 来「顺便」开聊 |

例如：用户开终端跑 `npm test`，同时侧栏仍可看历史会话。Agent 任务若在跑，互不替代：停止 Agent 不杀用户 PTY（除非实施时明确绑定——本课默认**不绑定**）。

## 4. 按依赖顺序实施与练习

整课一次交付；§4A 冻结合同与隔离，§4B 回挂与验收。

### §4A 阶段：冻结「独立交互宿主」合同

#### 步骤一：基线与孤儿面确认

1. 新 UUID 建本课基线；保留未提交改动/用户库/旧证据；不提交或重置 Git。  
2. 确认：`registerLocalTerminal` 已注册；`App.tsx` 无 `TerminalPanel`；Agent IPC 与 terminal IPC 通道分离。  
3. 阅读 `TerminalPanel` 生命周期：start/resize/write/close/dispose，列出必须清理的监听与 PTY。

**预期效果：** 知道「缺的是壳入口，不是从零写终端」。  
**常见错误：** 复刻一套新 IPC，丢掉现有有界解析。

#### 步骤二：冻结隔离规则（写入第9节）

写死并测试：

1. 工具层：`createAgentToolExecutor` / 工具名列表**不得**新增终端工具。  
2. 请求层：仅打开/关闭/输入终端时，`agent:start` / resume / 摘要 / 标题请求计数为 0。  
3. 数据层：PTY `data` 事件不得写入 conversation raw、checkpoint、workspace-read-evidence。  
4. 权限层：终端会话 ≠ 工作区授权；不因开终端提升 Agent 权限 revision 的「批准」含义。

**预期效果：** 后续实现有否决清单。  
**常见错误：** 「方便起见」把终端 cwd 设成 Agent 默认可写根并顺便授权。

#### 步骤三：交互合同（实施时选并测）

冻结至少：

1. **如何打开**：按钮位置 + 可选快捷键（避免与现有设置快捷键冲突）。  
2. **如何关闭**：面板关闭是否 `closeTerminal`；窗口关闭是否 `attachTerminalCleanup` 仍有效。  
3. **与设置页**：设置打开时终端焦点策略。  
4. **与会话切换**：是否保持 PTY；无论是否保持，**禁止**把缓冲注入新会话 Agent 历史。  
5. **与 Agent 忙碌**：允许并排；停止 Agent 默认不杀 PTY。

**预期效果：** UI 行为可验收，无「未定义」空洞。  
**常见错误：** 切会话泄漏上一个 sessionId 的监听器。

### §4B 阶段：回挂布局与分层验收

#### 步骤四：App 壳挂载

1. 在 `App.tsx`（或等价布局）挂载 `TerminalPanel`，用本地 state 控制显隐。  
2. 侧栏或标题栏增加「终端」入口；`onClose` 关闭面板并确保 PTY 停止。  
3. 引入必要 CSS；保证文件预览/聊天/设置仍可用，避免不可用的零高度 fit。  
4. 不做视觉大改；可访问性至少：关闭按钮可键盘到达。

**预期效果：** 开发桌面能看见并操作终端。  
**常见错误：** 挂载了但不 `fit`，或未 start 就显示「就绪」。

#### 步骤五：清理与失败路径

1. 面板卸载、窗口关闭、start 失败、shell 缺失：有界错误展示，无 Unhandled。  
2. 重复 start、快速开关：不残留孤儿进程（用任务管理器或夹具列进程核对，实施时选可行法）。  
3. 保持 Windows-only 诚实；非 Windows 若直接拒绝，UI 应显示明确错误而非空白。

**预期效果：** 关得干净。  
**常见错误：** 只 `dispose` xterm 不 `closeTerminal`。

#### 步骤六：隔离护栏测试

1. 断网/合成：打开终端路径上 Agent 请求探针为 0。  
2. 静态或单元：工具注册表快照不含终端相关工具名。  
3. 可选：故意在测试中断言 conversation 存储不因 PTY data 增长。  
4. 回归：第58 boundary / 默认 `npm test` 声明保留的 suite 不红；被动重开零请求精神保持。

**预期效果：** 「独立」有自动证据，不靠口头。  
**常见错误：** 只用截图当验收。

#### 步骤七：双桌面真实操作

1. 开发桌面 + Windows 目录包：打开终端 → 执行无害命令（如 `echo zonecodex-terminal-59`）→ 看见输出 → 关闭。  
2. 同时或先后跑一条既有固定 Agent 业务（可用合成）证明互不破坏。  
3. 合成/真实分记；本课不要求真实联网模型。

**预期效果：** 两版桌面可演示集成终端。  
**常见错误：** 只测开发态，目录包漏挂 assets/CSS。

#### 步骤八：文档收口

追加第9节：入口位置、交互合同终表、隔离证据、失败/未覆盖、制品身份、复跑命令。最小导航一行。八题待答。open 项继续后置。

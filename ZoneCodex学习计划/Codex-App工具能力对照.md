# Codex App 工具能力对照

此表依据 OpenAI 官方文档梳理可观察的 Codex App 能力，用于确定 ZoneCodex 的接入范围；两者不是同一产品，也不因界面或提示词相似而具有相同权限。

2026-10-06：[第43课：默认工作目录与统一执行权限](54-第四十三课-默认工作目录与统一执行权限.md)已实施默认目录、通用路径和统一权限策略，并按截图完成三模式菜单。风险审批模块已通过离线检查，但模型接线等待明确授权，自动审批尚未启用；Windows 命令沙箱仍未接入。没有新增路径授权流程或专用创建工具。

| 能力 | Codex App 官方说明 | ZoneCodex 状态 |
| --- | --- | --- |
| 无项目聊天与默认运行目录 | 可以不依附项目开始聊天；项目主目录提供默认工作目录，项目组织与系统沙箱边界分开。[项目与聊天](https://learn.chatgpt.com/docs/projects)、[沙箱](https://learn.chatgpt.com/docs/sandboxing) | 已接入每会话稳定默认目录，主进程解析后才选择工具历史；无工作区也使用同一本地工具链，支持相对/绝对路径。离线与桌面目录解析通过，真实模型文件闭环待明确授权。 |
| 工作区文件搜索、读取和修改 | 本地项目可附加文件夹；Codex 可在附加文件夹内搜索、读取和修改文件。[项目与聊天](https://learn.chatgpt.com/docs/projects) | 同一工具支持默认目录和显式工作区；范围内写入直接执行、越界按需批准、完整访问由用户选择。保留小文本上限、独占新建、完整读取与 SHA-256 冲突检查；隔离文件回归通过。 |
| 命令、测试和 Git 操作 | 本地命令受沙箱与审批约束；集成终端可运行项目检查和 Git 命令。[权限模式](https://learn.chatgpt.com/docs/permission-modes)、[集成终端](https://learn.chatgpt.com/docs/integrated-terminal) | 通用命令可指定 cwd；旧 npm 入口使用同一权限决策。未接入命令 OS 沙箱，默认权限必须批准具体非沙箱命令，完整访问由用户选择；没有专用 Git 工具，获批进程也没有工作区外/网络隔离。 |
| 变更审阅 | 审阅面板可查看未暂存、已暂存、提交、分支及最近一次操作的差异；`/review` 可报告问题。[代码审阅](https://learn.chatgpt.com/docs/code-review) | 未接入/可选：不把现有修改建议等同于完整的审阅面板或 `/review`。 |
| 权限与审批 | 沙箱限定文件和网络边界，审批决定越界操作何时暂停；有效范围内允许的操作无需每次确认，审批方式本身不会扩展沙箱。[沙箱](https://learn.chatgpt.com/docs/sandboxing)、[Windows 沙箱](https://learn.chatgpt.com/docs/windows/windows-sandbox) | 菜单显示“请求批准”“帮我批准”“完全访问权限”；前后两项沿用既有行为。“帮我批准”的独立风险判断与30秒超时离线检查通过，但模型接线等待明确外发及自动执行授权，当前选择时明确报尚未启用、保留实际模式。单次批准仍使用输入框上方弹窗；文件显示原因、操作与完整目标路径，命令显示原因、工作目录及可读命令。刷新清理待审批，停止或关闭使旧回应失效；风险判断不是 OS 沙箱。 |
| 网页搜索 | 官方提供一方网页搜索工具；本地 Codex 可配置索引、实时或禁用模式。[网页搜索](https://learn.chatgpt.com/docs/web-search) | 未接入/可选。 |
| 内置浏览器 | 桌面端浏览器可打开网站、交互、截图和验证页面，并对网站访问及敏感操作实施授权。[浏览器](https://learn.chatgpt.com/docs/browser) | 未接入/可选。 |
| 图像与附件输入 | 聊天可附加文件和图像作为本轮上下文。[项目与聊天](https://learn.chatgpt.com/docs/projects)、[图像输入](https://learn.chatgpt.com/docs/image-inputs) | 未接入/可选：不把现有文件快照能力表述为完整的图像输入能力。 |
| MCP、Skills 与插件 | 插件可组合 Skills、连接器和 MCP 工具；外部服务还需安装、认证与授权。[插件](https://learn.chatgpt.com/docs/plugins) | 未接入/可选。 |
| Computer Use | 这是需要安装和启用的插件，另受操作系统、地区和逐应用授权限制；文件与命令仍遵循原有权限边界。[Computer Use](https://learn.chatgpt.com/docs/computer-use) | 未接入/可选。 |

# 第三十六课：输入框草稿、快捷键与发送前交互收口

创建日期：2026-09-28。状态：课程已创建，待实施。

前一课：[第三十五课：会话标题、搜索、置顶与归档管理](46-第三十五课-会话标题搜索置顶与归档管理.md)。

第35课完成了会话库和会话侧栏管理，第36课收口聊天输入体验：让草稿、快捷键、输入法、忙碌保护、附件浮层和焦点行为在多会话与真实模型流式请求下保持一致。本课不改变 Agent Responses SSE、模型请求格式或工具循环。

## 1. 本课目标与边界

完成后应达到以下结果：

1. 切换会话时草稿不会串到另一个会话；每个会话的草稿只存在 renderer 内存中，不写入 `ConversationLibrary`、`conversation.json` 或工具历史。
2. 空白工作台也能保留尚未发送的草稿；首次发送被接受后只清空当前草稿。
3. `Enter` 发送，`Shift + Enter` 换行；中文输入法组合或候选确认期间按 Enter 不发送。
4. 空消息、超长消息、保存中、生成中、文件选择中、关闭保护和容量不足时不能提交请求；被拒绝时草稿保持不变。
5. 请求接受后清空草稿；异步失败或停止由失败/停止消息和已有重试入口处理，不自动复制一份新草稿造成重复发送。
6. 停止生成、切换会话、归档当前会话、关闭附件浮层后，焦点回到合理的输入框或触发按钮。
7. 附件浮层的 Escape、外部关闭和文件选择不会误触发送，也不会清空草稿。

本课不做：草稿持久化、跨窗口同步、自动保存草稿、语音输入、快捷命令、MCP、Skills、SSH、并发 Agent、自动批准或新的模型模式。所有聊天和附件请求继续统一使用真实模型流式响应。

## 2. 用 Vue 经验理解本课

| Vue 经验 | React / Electron 对应 | 本课用途 |
|---|---|---|
| 按路由保存的局部表单状态 | 以会话 ID 为键的 renderer 草稿映射 | 切换会话不丢草稿、不串草稿 |
| `@keydown.enter.exact` | `KeyboardEvent`、`isComposing` 和 `requestSubmit()` | 区分发送、换行和输入法确认 |
| `watch` 路由变化 | `useEffect` 或事件回调同步当前会话草稿 | 会话切换时读取正确草稿 |
| `disabled` 与提交前守卫 | `canSend`、`onSend` 返回值和 `useOperation` | 拒绝危险或重复提交 |
| `nextTick` 后聚焦 | DOM ref、`useLayoutEffect` 和返回焦点引用 | 发送、停止、浮层关闭后的键盘连续操作 |

草稿是页面交互状态，不是会话业务数据。发送是否被接受必须由 `conversation.send()` 的布尔结果决定，组件不能因为点击了按钮就先清空输入。

## 4. 按依赖顺序实施

### 第一步：建立草稿状态边界

先列出三个状态：当前活动会话草稿、按会话 ID 保存的内存草稿、没有活动会话时的空白工作台草稿。不要把草稿放进 `ConversationLibrary`，也不要在搜索结果或归档列表中复制会话对象。

切换会话时保存旧会话草稿，再读取新会话草稿。新建、归档当前会话、恢复会话和刷新后加载都必须有明确的空草稿行为。刷新不要求恢复草稿，因为本课不做草稿持久化。

预期效果：在会话 A 输入文字，切换到会话 B 后输入另一段文字，再切回 A，两段文字各自保留；首次发送空白工作台的草稿不会因为创建会话而丢失。

常见错误：使用一个全局字符串导致会话串稿；把草稿塞进会话快照导致自动保存、搜索和容量统计被无关输入污染；切换失败后提前覆盖原草稿。

### 第二步：收口提交和清空时机

`ChatInput` 只能在 `onSend` 返回 `true` 时清空草稿。空白、超长、容量不足、忙碌、保存或附件选择边界拒绝时，输入内容必须保留。

首次发送仍由第34课的 `useConversation.send()` 创建会话并传入明确的 `conversationId`。第36课只接收它的结果，不在 `ChatWorkspace` 里临时创建会话 ID，也不直接修改消息或任务状态。

预期效果：点击发送后同步参数校验失败，草稿仍可编辑；请求已接受后清空草稿；模型异步失败后，失败消息保留，重试使用已有来源，不额外自动提交一轮。

### 第三步：确认键盘和输入法语义

保留单一提交入口：表单 `onSubmit`。键盘事件只负责在非组合输入状态下把 Enter 转换为表单提交；`Shift + Enter` 保留换行；不要在 `onKeyDown` 中直接调用聊天请求。

需要观察：Windows 中文输入法候选确认、英文输入、粘贴多行文本、长文本自动增高、达到长度上限、停止按钮替换发送按钮、发送后焦点是否仍可连续输入。

### 第四步：处理焦点和浮层边界

输入框、附件按钮、附件浮层、修改预览和命令审查面板分别维护自己的返回焦点引用。Escape 关闭当前浮层；浮层关闭不能触发 form submit；停止生成后把焦点交回输入框，避免用户必须用鼠标重新点击。

不要为了焦点恢复引入全局事件总线，也不要让附件选择完成后自动发送。文件选择、移除文件和撤销快照仍服从 `canEdit` 与操作互斥。

### 第五步：处理切换、归档和刷新

切换或归档发生在生成、保存、文件选择或关闭保护期间时，沿用第35课的拒绝边界。操作成功后只更新活动会话和当前草稿选择，不清理其他会话的内存草稿，除非用户明确清空该会话。

刷新后会话标题、消息、任务、置顶和归档状态从磁盘恢复；草稿恢复为空属于本课定义的行为。页面重新加载后不应残留旧请求的焦点、重试来源或一次性附件许可。

## 5. 验收矩阵

| 场景 | 必须观察 |
|---|---|
| 会话切换 | A、B 草稿互不串写；切换失败保留原草稿 |
| 空白工作台 | 无活动会话时输入草稿；首次发送接受后创建会话并清空当前草稿 |
| Enter | 普通 Enter 提交一次；Shift+Enter 只换行 |
| 中文输入法 | 组合输入和候选确认期间 Enter 不提交 |
| 拒绝发送 | 空白、超长、保存中、生成中、选择中、关闭保护和容量不足时草稿不丢 |
| 异步失败 | 失败消息和任务记录保留；不自动复制草稿或重复请求 |
| 停止生成 | 请求停止后输入框恢复可编辑，焦点回到输入框 |
| 附件浮层 | Escape/外部关闭可用，文件操作不误触表单发送，文字草稿不变 |
| 归档当前会话 | 按第35课规则切换到其他活动会话或空白工作台，草稿映射不污染其他会话 |
| 刷新 | 持久化会话元数据恢复；草稿按本课约定为空，旧请求和许可不恢复 |
| 真实流式 | 文字仍由 Agent SSE 增量写入助手占位消息；本课没有第二套回复路径 |

验证命令以当前仓库实际存在的命令为准：至少运行 `npm run typecheck:node`、`npx electron-vite build` 和 `git diff --check`。完整 `npm run typecheck`、`npm run build` 和 lint 若继续受到 `WorkspaceStatus.tsx` 的既有未使用声明阻断，必须单独记录。仓库已删除模拟模型和桌面 fixture，不新增模拟回归脚本；真实网关桌面观察不到时标记为“待验收”。

## 8. 本课实施记录（2026-09-28）

- `ChatWorkspace` 保持组件实例稳定，以 renderer 内存 `Map<conversationId | null, string>` 保存草稿；活动会话切换、空白工作台首次发送、归档切换和刷新均不把草稿写入 `ConversationLibrary`、`conversation.json`、工具历史或任务记录。首次发送仅在 `conversation.send()` 返回 `true` 后清空当前草稿，拒绝时保留原文。
- `ChatInput` 继续使用单一表单提交入口：普通 `Enter` 调用 `requestSubmit()`，`Shift + Enter` 保留换行；`isComposing`、组合输入 ref 和 keyCode `229` 阻止中文输入法候选确认误发。长度、空白和 `disabled` 边界在提交前再次检查；`useConversation` 的统一 `canSubmit` 还会拦截容量不足、满会话数、保存/生成/选择/关闭保护期间的发送、编辑发送和重试；生成停止后输入框恢复可编辑并尝试恢复焦点。
- `ComposerAttachments` 的按钮均为非提交按钮；浮层用原生 popover 自动外部关闭，Escape 显式阻止默认提交并关闭，内部关闭后把焦点返回附件触发按钮，外部点击不抢焦点。活动会话切换或归档时浮层关闭但不抢回侧栏焦点。文件选择、移除附件和预览不会改写文字草稿。
- 已实际通过：`npm run typecheck:node`、`npx electron-vite build`、附件组件定向 ESLint 和 `git diff --check`。
- `npm run typecheck`、`npm run build`、`npm run lint -- --quiet` 的完整结果需以最终整合后的工作区为准；当前 Web 检查仍会报告用户已有 `src/renderer/src/features/project/WorkspaceStatus.tsx` 中 `taskLabel`、`taskTime`、`taskSummary`、`selection`、`canRetryTask`、`onRetryTask`、`recentTasks`、`task` 未使用（TS6133），本课未修改该文件。
- 未实际操作真实网关桌面窗口，以下仍待验收：A/B 草稿切换、空白工作台首次发送、Enter/Shift+Enter、中文输入法候选确认、拒绝发送保留草稿、停止后焦点、附件 Escape/外部关闭、归档/恢复/刷新，以及 Agent Responses SSE 增量显示。真实请求继续沿用既有统一 SSE 和 Agent 工具循环，没有新增普通文本或模拟回复路径。

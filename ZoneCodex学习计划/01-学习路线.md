# 学习路线

## 学习目标

最终做出一个自己的 AI 桌面助手：管理聊天、流式回复、选择工作目录、使用本地终端、连接远程环境、调用 MCP 工具，并能够打包和更新。

第一版只做单窗口、单用户和单模型配置。账户计费、多窗口协作等不属于当前学习范围。

## 阶段 0：读懂现有骨架

学习：main、preload、renderer 的职责，应用生命周期，开发和打包后的加载方式，IPC 的基本概念。

实践：运行自己的模板，点击 Send IPC，在主进程日志中找到 pong；修改根组件的一句文字。

验收：能指出两个不同的入口文件；能说明为什么界面日志与主进程日志出现的位置不同；能说明 preload 不等于独立的第三个进程。

文档：[第一课](03-第一课-入口与通信.md)。

## 阶段 1：React + TypeScript 聊天界面

学习：函数组件、TSX、Props、useState、受控输入、列表 key、不可变更新，以及事件和消息的类型定义。结合 Vue 对照学习，不把 useEffect 简单等同于 watch。

实践：拆分 ChatPage、MessageList、MessageItem、ChatInput；定义 Message 类型，包含 id、role、content；实现发送和模拟回复。

验收：空消息不可发送；连续消息不会丢失；列表 key 稳定；输入有明确类型；能解释状态为什么放在相应组件中。

暂不引入全局状态库。派生值优先直接计算，不为每个值添加 useEffect 或 useMemo。

## 阶段 2：Electron 类型化本地接口

学习：contextBridge、ipcRenderer.invoke、ipcMain.handle、返回类型、取消与异常。类型检查不能替代运行时参数校验。

实践：通过 window.api.selectFolder() 打开文件夹选择器，在界面显示结果；新增共享接口类型，并同步 preload 的 Window 声明。

验收：能处理取消选择；界面不直接访问 Node 文件 API；接口只暴露完成业务所需的能力；能画出请求与返回路径。

## 阶段 3：真实模型与流式聊天

学习：HTTP、模型消息格式、流式事件解析、AbortController、请求状态和错误处理。

实践：先接入一个模型服务；由主进程管理请求，通过明确的 IPC 接口向界面发送增量内容；实现停止生成和失败提示。

拆课安排：[第五课](09-第五课-真实模型请求与异步状态.md)先完成 gpt-5.5 Responses 非流式单轮问答、等待与错误恢复；[第六课](10-第六课-多轮上下文与清空对话.md)实现简化的多轮文本上下文、完整问答裁剪与清空对话；[第七课](11-第七课-模拟流与停止生成.md)在独立练习区实现本地模拟流、主动停止和订阅清理；之后接入真实流式输出。进入复杂推理或工具场景前，另行设计保留完整 Responses output 与 phase 的协议历史。

验收：凭据不写入源码和日志；增量片段正确拼接；停止后不再追加；重复发送策略明确；失败后界面能恢复操作。先用模拟流验证，再做少量真实调用。

真实流入门：[第八课](12-第八课-真实流式响应与网络取消.md)使用独立单轮区学习 SSE 解码、分帧、Responses 终态和网络取消；[第九课](13-第九课-正式聊天的流式消息与上下文.md)合并至正式多轮聊天，处理助手占位、停止/失败和成功问答上下文。

## 阶段 4：对话与设置持久化

入门文档：[第十课](14-第十课-聊天记录的本地保存与恢复.md)。先实现启动读取与手动保存，用固定 userData 文件、版本校验、串行写入和损坏保护建立明确行为，[第十一课](15-第十一课-防抖自动保存与失败重试.md)补齐操作保护，实现空闲防抖自动保存、失败暂停与手动重试；[第十二课](18-第十二课-退出保护与保存后关闭.md)统一拦截窗口关闭，学习继续编辑、不保存关闭、保存成功后关闭，以及忙碌时留窗。

学习：Electron userData 目录、配置结构、数据版本、文件写入与恢复。初版用 JSON，确有查询需求后再考虑 SQLite。

实践：保存对话和选中的工作目录，重启后恢复；凭据采用合适的系统安全存储方案，不与普通聊天 JSON 混存。

验收：重启能恢复；文件缺失时有默认状态；损坏数据不会被静默覆盖；聊天内容和敏感配置有清楚的存储边界。

## 第十一课后的工程整理

多会话拆课：[第十三课](19-第十三课-多会话数据结构与版本迁移.md)先实现版本 2 会话库、活动 ID、旧版纯数据迁移与隔离验收；[第十四课](20-第十四课-多会话存储接入与侧栏切换.md)接正式存储兼容迁移、旧文件备份、整库保存、侧栏新建/切换与流式请求的会话归属。第十三课不直接改写用户磁盘记录；第十四课按步骤实现并先通过临时目录存储验收，再启动正式应用。

已按用户要求先完成[工作台布局与代码整理](17-工程整理与工作台布局.md)。这次作为后续课程基线：先复习自定义 Hook、单一数据源和操作互斥，再做退出保护、多会话及消息 Markdown 展示，之后进入终端。后续示例使用 features/chat、features/conversation 与 components/layout 的新结构，不再把所有逻辑写进 App。

## 消息展示补充

[第十五课：消息 Markdown 展示与安全渲染](21-第十五课-消息Markdown展示与安全渲染.md)：只将助手原始文本派生为排版，支持标题、列表、引用、代码块及 GFM 表格；保持会话存储和模型上下文为原文。跳过原生 HTML、限制 URL、链接仅展示和图片占位，不新增测试文件。完成后再进入本地终端。

## 阶段 5：本地终端

拆课安排：[第十六课](22-第十六课-终端界面入门与生命周期.md)完成显示层入门；[第十七课](24-第十七课-真实PowerShell与终端进程生命周期.md)接入 node-pty、类型化 IPC、固定用户主目录的 PowerShell、尺寸与进程清理。第十七课已收到完成反馈，原生重建与类型修正结果见学习进度，实际交互和 PID 清理专项未由助手逐项独立重跑；自测讲解已追加，原理仍待巩固。

学习：xterm.js 是终端界面，node-pty 提供伪终端进程；理解输入、输出、窗口尺寸、会话生命周期和原生依赖。

实践：先由用户手动使用终端，运行一个固定工作目录下的 PowerShell 会话，再实现输入、输出、调整大小和关闭。

验收：可交互输入；缩放时正确调整行列；关闭会话能释放资源；重复打开不重复注册监听器；错误退出可见。

终端能力完成后，再设计模型执行命令的授权流程，不直接把任意模型输出作为命令执行。

## 阶段 6：SSH 远程环境

学习：SSH 连接与 shell 通道、认证、主机密钥验证、超时和断线。使用自己有权访问的测试主机。

实践：通过维护中的 SSH 客户端库建立远程终端，复用终端界面；随后抽象本地与远程会话的公共接口。

验收：认证失败、超时、断线均可理解；未知或变化的主机密钥得到明确处理；凭据不进源码或日志；断线后不会误显示为已连接。

没有测试主机时先完成接口与模拟测试，真实连接验收保持待完成。

## 阶段 7：MCP 与模型工具循环

第十八课最小工具循环已收到完成反馈，自测讲解已追加。[第十九课：工具循环接入正式聊天](26-第十九课-工具循环接入正式聊天.md)先统一输入框、进度与停止，并保持会话归属和普通流式聊天。[第二十课](27-第二十课-工具历史的保存与恢复.md)已收到完成反馈；[第二十一课：项目文件读取与搜索](28-第二十一课-项目文件读取与搜索.md)在正式聊天中学习只读快照、读取/搜索、路径边界、历史范围隔离和授权撤销，安排版本 4 迁移。之后学习差异审查、授权写入和命令执行，再扩展 MCP。下方 MCP 实践属于后续安排。

学习：MCP client/server、传输方式、工具发现、参数 schema、工具调用和返回值；区分 MCP 协议与模型自己的工具调用机制。

实践：先连接一个本地、只读的教学 MCP server，列出工具并手动调用；然后将工具描述提供给模型，接收调用请求、校验与执行，并把结果交回模型继续回答。

验收：手动调用与模型调用均能解释；超时和参数错误可恢复；工具描述作为外部数据处理；涉及文件修改或命令执行的操作有具体的用户授权边界。

## 阶段 8：打包与自动更新

学习：electron-vite 编译与 electron-builder 打包的区别、版本号、安装包、更新元数据、发布渠道和签名。

实践：先构建 Windows 安装包；再使用自己控制的测试更新源，制作两个版本验证更新。

验收：打包版能启动，资源路径有效；安装目录与用户数据目录分离；确实完成低版本到高版本更新；无更新、下载失败、重启安装的状态清楚。

当前模板的 example.com 地址是占位值，安装了 electron-updater 不代表已实现自动更新。公开发布单独安排。

## 阶段 9：与 NextCoWork 对照复盘

实践：选择聊天、终端或环境管理中的一个模块，对照参考项目的当前源码，记录职责划分、状态流动、错误处理的差异，再做一项有理由的改进。

验收：能独立解释关键调用链；至少完成一次功能修复；文档中分清参考项目事实、自己的实现和改进建议。

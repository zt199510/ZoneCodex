# 第三十八课：工作区任务状态、错误展示与安全重试

## 1. 本课目标与前置条件

本课承接第三十二至三十四课的任务生命周期、刷新对账和单轮请求绑定，也承接第三十七课的真实 Agent Responses SSE 请求。目标是提供简洁的工作区状态反馈，让用户知道当前是否正在加载、保存、选择文件、生成或提交；错误详情和重试继续放在聊天消息中。

本课不新增模型入口、普通文本请求、模拟模型或第二套回复路径。聊天消息、工具调用记录、工作区快照和任务记录继续使用既有真实链路。

## 2. 用 Vue 经验理解本课

`WorkspaceStatus` 相当于一个只读的派生视图组件：当前操作和项目上下文是输入，状态文字是计算结果，不再复制成另一份可变状态。错误消息和“重新生成”按钮属于聊天消息组件，不在状态条中重复一份。

React Hook 中的 `ref` 保存的是本次进程仍可使用的请求来源，类似 Vue 中不会触发渲染的实例状态。持久化消息只能说明过去发生过什么，不能单独恢复附件授权、工具历史或请求上下文，因此刷新后不能凭消息内容猜测并重试。

## 3. 实际文件与职责

- `src/renderer/src/features/project/WorkspaceStatus.tsx`：展示项目上下文、当前操作和文件授权边界。
- `src/renderer/src/features/chat/useChatRequest.ts`：保存当前进程的重试来源，接收主进程任务事件，并忽略刷新对账后终态任务的迟到状态。
- `src/renderer/src/features/conversation/useConversation.ts`：保留消息级重试的会话、项目快照和原始请求来源校验。
- `src/shared/task.ts`：提供任务状态集合、终态判断和记录容量边界。
- `src/main/agent/task-registry.ts`、`src/main/agent/agent-ipc.ts`：继续作为任务状态和真实 Agent 执行的主进程权威，不在本课新增回复通道。

## 4. 本课实施内容

### 4.1 状态与错误展示

工作区状态条只显示项目上下文、当前操作和文件授权状态。失败、取消、超时和中断详情由聊天消息和错误提示承载；状态条不重复显示任务历史或底层诊断字段。

### 4.2 消息级错误与重试

失败和停止继续显示在助手消息中，并沿用已有“重新生成”入口。`useChatRequest` 只复用当前进程捕获的原始模式、附件快照和工具历史来源；刷新后没有这份来源时隐藏消息级重试。重试通过已有 `send` 创建新的用户消息、助手消息、`requestId` 和 `taskId`，旧任务记录不被改写。

### 4.3 刷新与迟到事件

任务事件仍统一来自主进程 `task:state`。renderer 对账后已经进入终态的任务视为封闭记录，之后到达的旧状态事件不会重新打开、替换或污染该记录；已从会话中移除的未知任务事件也会被忽略。刷新不会恢复旧的 `AbortController`、授权或重试来源。

## 5. 验收条件

- 状态条能显示项目上下文、当前操作和文件授权边界，不重复承载聊天错误详情。
- 失败和停止消息能区分显示；消息级“重新生成”只在安全条件满足时出现。
- 重试成功后产生新的 `requestId` 和 `taskId`，原记录仍保留。
- 刷新对账为 `interrupted` 后，迟到的 `running`、`cancelled` 等事件不能改写该终态。
- 所有聊天和附件请求仍通过真实 Agent Responses SSE，任务记录和工具历史继续沿用原协议。

本课实际修改了 `WorkspaceStatus.tsx`、`ChatWorkspace.tsx`、`useChatRequest.ts` 和 `useConversation.ts`。删除了状态条中的最近任务列表和任务级重试入口，保留聊天消息级重试及其安全来源校验。没有修改第37课的标题 IPC、标题协议或模型链路，也没有把草稿、重试来源写入会话库、`conversation.json`、工具历史或任务记录。

已通过：

这些检查只证明静态类型、构建和 lint 结果；真实模型网关和桌面窗口中的失败、取消、超时、刷新迟到事件、重试身份变化仍需要实际观察。

## 7. 待验收与边界

当前环境未获得可记录的桌面观察结果：Electron GPU 子进程无法稳定启动，备用桌面控制服务未配置。因此以下项目标记为“待验收”：工作区状态条在真实窗口中的排版、真实 SSE 增量、失败/停止消息与消息级重试、刷新后的中断显示、迟到事件、A/B 会话切换后的重试保护，以及新的 `taskId`/`requestId` 是否在真实网关场景中可观察。

本课仍不实现跨刷新恢复原始请求、并发 Agent、自动批准、任意命令、MCP、Skills、SSH 或永久删除。

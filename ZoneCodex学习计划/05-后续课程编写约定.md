# 后续课程编写约定

## 协作方式

学习者负责亲手完成本课核心代码和解释调用过程；助手负责结合实际文件讲解、提供范围明确的练习、检查结果和更新文档。用户明确要求直接实现时，再由助手执行对应代码工作。

不一次性生成完整应用。每课完成一个可观察的小功能，复杂能力分成多课。

## 每课文档结构

1. 本课目标与前置条件。
2. 用 Vue 经验解释需要迁移的概念。
3. 本课涉及的实际文件及其职责。
4. 按依赖顺序安排的操作与代码练习。
5. 每一步的预期效果和常见错误。
6. 自测题与明确验收条件。
7. 学习记录与下一步。

文档使用 Markdown，新增课程按顺序编号，更新 README 导航。路线发生变化时同步修改学习路线和进度表。

## 校验与记录

- 先核对当前项目源码，避免把其他模板版本的结构当作事实。
- 把已验证、用户报告和待验证的结果区分记录。
- 界面小改动以实际观察为主；涉及类型或逻辑的改动运行相应检查。
- 网络流、进程、SSH 和工具执行要验证错误与资源清理路径。
- 日志和截图不包含 API 密钥、密码或私钥。
- 新增依赖时解释作用、所在层以及为什么当前需要它。
- 下一课根据上一课验收情况展开，不提前标记掌握。
